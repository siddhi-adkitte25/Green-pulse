# 🌱 Green Pulse India

Green Pulse India is a full-stack web application designed to organize and manage environmental cleanup events. The platform allows administrators, volunteers, and delivery personnel to collaborate efficiently through secure role-based access control.

---

## 🚀 Features

- 🔐 JWT-based Authentication & Authorization
- 👥 Role-Based Access Control (Admin, Volunteer, Delivery)
- 📅 Event Creation and Management
- 📝 Volunteer Registration for Events
- ♻️ Waste Collection Tracking
- 📊 Dashboard for Different User Roles
- 🔄 RESTful API Integration
- 💾 Secure Data Storage with MySQL

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/GreenPulseIndia.git
```

### Backend Setup

```bash
cd backend
mvn spring-boot:run
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
